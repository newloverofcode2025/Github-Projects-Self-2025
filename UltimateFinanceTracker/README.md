# Ultimate Finance Tracker

A personal finance tracker with advanced features like user authentication, multi-currency support, and export/import functionality.

## Features
- Add income and expenses.
- Visualize data with charts.
- Export transactions as CSV or PDF.
- Multi-currency support.
- Dark mode toggle.
